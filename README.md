# hxyfront-62004 滑雪板调校维护

源提示词编号：6

面向滑雪板旺季车间的装备维护前端原型。系统演示离线工单回柜后的编号合并、冲突双版本保留、完工门禁、同板并发先到生效、工位容量排队、刃角基线重算和失败片段重试。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62004

## 业务规则演示

- **按编号合并**：雪板档案 `B-201`、调校工单 `WO-201`、底板损伤记录 `D-301/302/303` 分别按编号对齐。
- **双方修改不覆盖**：柜台与车间都修改刃角或修补位置时，两版同时保留；必须人工选定一版后 `WO-201` 才能完工。
- **单方改动自动并入**：仅柜台或仅车间修改的字段可直接进入正式档案或损伤记录。
- **失败片段重试**：`D-302` 模拟柜台锁冲突，只会重试这个未并入字段，已经成功的合并项不会重复写入。
- **同一块雪板先到生效**：同时提交两张 `B-209` 工单时，序列号更靠前的 `WO-209A` 生效，`WO-209B` 标记为未生效且不能覆盖数据。
- **工位容量与排队**：容量为 2；满员后的新任务进入 FIFO 队列，任务完工释放工位后自动补位。
- **刃角基线重算**：修改 `B-201` 基线后，未完工方案立即失效并按原偏移重算；冲突选择会被重置。已完工记录冻结，不受基线变化影响。
- **历史记录**：完工工单保存冻结刃角、打蜡结果和客户摘要，可按完工状态查看。
